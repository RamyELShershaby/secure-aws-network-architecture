# Architecture Diagrams

Place the sanitized project diagrams in this directory.

Recommended files:
- `architecture.png` — overall AWS network and request-flow diagram.
- `connectivity.png` — VPC Peering, PrivateLink, Transit Gateway, and VPN connectivity.
- `monitoring-and-ir.png` — Flow Logs, Athena, CloudWatch, GuardDuty, EventBridge, and Lambda response flow.

Use legible labels and a legend. Avoid console screenshots as the main architecture diagram. Do not include AWS account IDs, resource ARNs/IDs, public IPs, private keys, access tokens, or personal email addresses.
